# Hub Tech Codex

**One identity. Many paths.** A topology-first environment for discovering repositories, tools, databases, APIs, agents and the relationships between them. GitHub is the initial bounded source and route; source ownership stays with its owner.

## Run the environment

Requires Node.js 22 or later. No packages to install.

```sh
npm start
# open http://127.0.0.1:4173
npm test
npm run check
```

### A complete first traversal

1. Explore the constellation, directory or within-hub lens.
2. Select an identity and follow outgoing or incoming relationships.
3. Observe an explicitly selected public GitHub repository; inspect its timestamp, pinned revision and declared/unknown licence.
4. Open Diamond proof and supply a package manifest. The inert local inventory parses dependency declarations without running package code.
5. Inspect the receipt. Remove the fixture approval to see refusal before work.

The dependency inventory is a **local demonstration**, not a live Diamond service, vulnerability scan or authority grant. The seed graph is labelled design/declaration data; imported public metadata is an observation, not certification. UI observations are session-local and are not silently saved.

For intentional source capture:

```sh
npm run discover -- hometradescompany-director/Hub-Tech-Codex
```

The CLI emits JSON. Public GitHub rate limits/refusals remain explicit errors. No authentication token is required or accepted by this browser-facing adapter. See the official [repository API](https://docs.github.com/en/rest/repos/repos#get-a-repository) and [versioning guide](https://docs.github.com/en/rest/about-the-rest-api/api-versions).
