# Hub Tech Codex agent contract

Read README.md, docs/ARCHITECTURE.md and the relevant docs/paths brief before work.

- GitHub is the bounded source and route. Canonical source stays with its owner.
- Stable identities, typed edges, provenance and reversible navigation are load-bearing.
- One relation supplies both directions; neither direction grants authority.
- JSON describes data/views. Never turn imported JSON into executable HTML, CSS, JavaScript or shell commands.
- Public metadata discovery is not permission to install, execute, redistribute or call private services.
- No proprietary Atlas source in this Apache-2.0 repository. Reference versioned public contracts; record unknowns.
- Diamond's authority gate and closed operation catalogue remain Diamond-owned. The local demo is inert, not a live Diamond integration.
- Never put credentials in client JavaScript, source observations, URL queries or receipts.
- Main must remain runnable and coherent. Each feature branch reads its dependencies; merge changes with tests and review. A branch's existence does not mark its scope implemented.
- Add no package dependency without a concrete reason and licence/provenance record.
- Run npm test and npm run check. Run optional browser smoke when a browser is available; report a blocked check accurately.
- Authoritative status must name evidence, scope and observation time. No aggregate universal trust, human-worth or "100% integrity" score.

Development branch specs are declarations, not autonomous permission for spending, deployment, health decisions or wider execution.
